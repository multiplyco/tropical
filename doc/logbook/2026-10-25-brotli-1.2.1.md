# 2026-10-25 — Brotli 1.2.1

The bundled Brotli encoder is rebuilt from [1.2.1](https://github.com/google/brotli/releases/tag/v1.2.1).
That release fixes CVE-2026-111497 in the decoder. Tropical compiles `c/common/*.c` and `c/enc/*.c`, excluding the
affected `c/dec/decode.c`, so its Brotli compression was not affected. The
[upstream fix](https://github.com/google/brotli/commit/0ed4268a4401abcb44720963) changes only the decoder and its
header. Between 1.2.0 and 1.2.1, the other changes are the changelog and `c/common/version.h`; encoder code is unchanged.

## Source verification

that commit both through Git and GitHub's API. GitHub's release-tag archive names the same commit in its tar header.
Each of its 167 files hashes to the corresponding Git blob, and the archive's file set and contents match
`git archive` of that commit, including the omissions specified by `.gitattributes`'s `export-ignore` attributes.

Archive: `https://github.com/google/brotli/archive/refs/tags/v1.2.1.tar.gz`.

The version, checksum and provenance comment are updated in `native/build-brotli.sh`.

## Build

Built with `bb native:brotli`, using the existing flags and pinned Debian 12 images:

- macOS: Apple clang 21.0.0 (`clang-2100.3.34.2`), one universal library for x86-64 and arm64, targeting macOS 11.
- Linux: GCC 12.2.0 (`Debian 12.2.0-14+deb12u1`) for x86-64 and aarch64. The highest required glibc symbol versions
  remain GLIBC_2.14 and GLIBC_2.17, respectively.

## Validation

`bb test`, in a fresh JVM on macOS arm64 with JDK 27: 197 tests, 6,243 assertions, no failures; all 15 browser
JavaScript tests passed. Babashka's process-cleanup hooks reported sandbox-denied `sysctl` calls; the test command
exited successfully.

`bb test:linux all`, under JDK 25: the glibc suites on x86-64 and arm64, and the musl suite on arm64, each passed
197 tests and 6,243 assertions. The x86-64 musl suite had one failure in
`hooks-test/hooks-reading-the-same-thing-in-one-render-share-it`: its resource-opening assertion expected `[4 5]`
and observed `[5 4]`. That test uses the runtime harness without compression. All compression tests passed on all
four targets. Rerunning the complete x86-64 musl suite with `bb test:linux amd64-musl` passed all 197 tests and
6,243 assertions, without changes to the test or library code.

`bash -n native/build-brotli.sh`, `bb version:check` and `git diff --check` passed.
